# Aerial One for Windows: downloads

Download page: https://aerialone.app/download/

This repository only holds the Aerial One installer and the update file the app checks for new versions. The app's code is not here.

- `AerialOne-Setup.exe`: the latest version (what the download page links to)
- `AerialOne-Setup-<version>.exe`, `.blockmap`, `latest.yml`: used by the app's automatic updates
